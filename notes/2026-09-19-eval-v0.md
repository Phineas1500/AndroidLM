# Eval v0: quantization and naive retrieval (2026-09-19)

32 questions (`eval/questions_v0.jsonl`), Qwen3.6-35B-A3B, thinking off, 450-token limit,
graded 0-10 by a Claude subagent from its own knowledge (no web checks), reference = what a
frontier model with web search would give. Per-question grades: `eval/grades_v0.json`.

| Set | Mean | Answers with a confident hallucination |
|---|---|---|
| 2-bit (UD-Q2_K_XL), closed-book | 7.58 | 12 / 32 |
| 3-bit (UD-IQ3_XXS), closed-book | 7.36 | 9 / 32 |
| 2-bit + naive BM25 retrieval | 5.30 | 6 / 32 |

Per category (2-bit / 3-bit / retrieval): explain 7.9 / 7.8 / 5.8, compare 6.5 / 6.5 / 3.8,
synthesis 7.4 / 7.4 / 6.3, multihop 8.7 / 9.2 / 5.7, travel 5.75 / 4.75 / 3.6,
medical 8.3 / 8.0 / 3.8, numeric 8.0 / 7.7 / 6.3, abstain 9.0 / 7.5 / 8.25.

## Reading

- No measurable quality gap between 2-bit and 3-bit on this set (0.2 is inside grading noise).
  2-bit is also faster (8.1 vs 5.8 tok/s decode on the VM), so 2-bit K-quant is the default.
- The biggest closed-book loss is the 450-token cutoff: long preambles, tables and LaTeX meant
  the second half of many compare/travel questions was never reached.
- Naive retrieval (BM25 over the raw question, strict "answer from the sources" prompt) made
  answers worse. Retrieval was rated good on 8 questions, partial on 15, miss on 9; with good
  retrieval the mean was 7.6, otherwise about 4.5. Causes: generic words ("argument",
  "evidence", "compare") outranking the topic; right article but wrong section; the model
  refusing well-known facts because the sources lacked them; distractor passages leaking into
  answers (medical-abortion warning signs in traveller's-diarrhoea advice).
- All three sets handled the two abstain traps without inventing content.

## Changes made for v1 (`scripts/rag.py`)

1. The model first names up to 4 Wikipedia article titles (one per part of the question);
   each contributes its lead plus best-matching sections, scored with a tf-saturated idf score
   and a heading bonus.
2. Whole-index BM25 only fills leftover budget, and only with passages that contain the
   planned topic words.
3. Answer prompt: sources support the model's knowledge rather than replace it; ignore
   off-topic sources; never withhold well-known facts or safety advice; answer every part
   first; no preamble, LaTeX or visible deliberation. Limit raised to 600 tokens.
4. Closed-book is re-run with the same prompt and limit (`--mode none`) so v1 compares like
   with like.

Known gap: FineWiki has no redirects, so a planned title like "Rent control" cannot resolve to
"Rent regulation" except through fallback search. A redirect table is the structural fix.
